# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in Mnestix Browser, please report it responsibly using one of the following channels:

- **Eclipse Foundation security landing page:** [eclipse.org/security](https://www.eclipse.org/security/) — general guidance on reporting vulnerabilities in Eclipse projects, including a dedicated issue tracker for confidential reports. The Eclipse Foundation's Project Security Incident Response Team (PSIRT) is a registered CVE Numbering Authority (CNA) and coordinates with this project's committers to triage and resolve reports.
- **Eclipse Foundation security contact:** [security@eclipse-foundation.org](mailto:security@eclipse-foundation.org)
- **Project contact:** [mnestix@xitaso.com](mailto:mnestix@xitaso.com)

Please include as much detail as possible (affected version, reproduction steps, potential impact) so the report can be triaged quickly.

## Supported Versions

Only the latest released version of Mnestix Browser is supported with security patches.

| Version              | Supported |
| --------------------- | --------- |
| Latest release       | ✅        |
| Older releases        | ❌        |

We recommend always running the most recent release.
